# Dhivehi & Bilingual Flashcard Studio (`ދިވެހި ބަސްކޮށާރު`)

A fast, ad-free Quizlet replacement crafted with authentic **FarumaThaana** typography, warm obsidian & antique brass manuscript styling, 3D interactive cards, multiple-choice Learn mode, Quizlet `.txt`/`.csv` import & export, and A4 printable study sheets.

## Features

- **Pre-Loaded Default Deck:** `"Dhivehi Baskoshaaru U3–U5"` (`ދިވެހި ބަސްކޮށާރު U3-U5`) with 30 built-in Dhivehi vocabulary cards available immediately on any device.
- **Multi-Deck Switcher & Quizlet Importer/Exporter:** Create, edit, delete, and export custom decks in `localStorage` with customizable Term/Row delimiters (`Tab`, `Dash`, `Comma`, `New line`, `Double new line`, `Semicolon`, or `Custom`), `.txt`/`.csv` upload, Term/Definition swap, and live preview.
- **3D Interactive Flashcards:** Crisp RTL `FarumaThaana` typography, iOS Safari 3D flip fix, swipe navigation, and **Front Side: Term / Definition** toggle (`T`).
- **Free Learn / Quiz Mode:** 4-option multiple choice with keyboard shortcuts (`1`–`4`), instant green/red feedback, live streak & accuracy tracking, and end-of-round **Retry Missed Cards**.
- **Browse All & A4 Print Sheets:** Instant Thaana/English search, memorized/favorite filters, and clean printable white A4 cards (`2×2`, `2×3`, `3×3`).

## Getting Started

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
